How

How do you design for everyone?

Each technique is one more way Chip “talks” without words.

Semantic HTML

  • Landmarks: header, nav, main, footer. No divs.
  • Tables for data only, with a caption and th scope.

Headings

  • One h1 per page, then h2 and h3 in order.

Alt text

  • Describe what Chip is doing and why it matters. Empty alt for decorative images.

Captions and transcripts

  • Captions on Chip skit videos, transcripts for anything spoken.

Color and contrast

  • 4.5:1 for body text. Never use color alone to carry meaning.

Type and plain language

  • Readable fonts, comfortable size and line height, short chunks of text.

Keyboard access

  • Skip link, logical tab order, visible focus ring.

Mobile first and touch

  • Grid for 2D layout, flexbox for 1D. 48px tap targets. Works at 200% zoom.

Forms, ARIA and motion

  • A label on every field, fieldset and legend.
  • Use ARIA only when HTML can't do the job. Respect reduced motion.

Testing

  • Nu HTML Checker, HTML5 Outliner, WAVE, Silktide, Lighthouse, keyboard-only test.
  • Screen readers: VoiceOver, NVDA, TalkBack.
